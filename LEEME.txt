BANDAS EN CASA - versión 2.3

QUÉ HAY EN LA CARPETA (todo junto, sin subcarpetas)
  index.html              la app (tipografías incluidas dentro)
  sw.js                   permite usarla sin conexión
  manifest.webmanifest    permite instalarla en el móvil
  icon-*.png, apple-touch-icon.png
  *.webp                  122 fotos (2 por ejercicio, 61 ejercicios)

ARCHIVO SUELTO PARA EL ORDENADOR
  bandas-en-casa-un-solo-archivo.html
  Es la misma app con las fotos y las tipografías dentro (unos 4,5 MB).
  Se abre con doble clic, sin más archivos y sin internet.
  (No se instala en el móvil: para eso usa la versión de GitHub Pages.)

SI NO SE VEN LAS FOTOS
  - Con la carpeta: no abras index.html desde dentro del ZIP. Extrae todo
    (clic derecho > Extraer todo) y abre el index.html de la carpeta extraída.
  - En GitHub Pages: todas las fotos (.webp) tienen que estar junto a index.html.
    Ajustes > «Comprobar fotos» te dice cuántas faltan.

SUBIR A GITHUB PAGES DESDE EL NAVEGADOR
  Desde el navegador GitHub deja subir unos 100 archivos por vez. Sube en tandas
  (unos 60 por tanda) en https://github.com/TU-USUARIO/TU-REPO/upload/main
  y pulsa "Commit changes" después de cada una.
  Con GitHub Desktop o con git no hay ese límite.

SI CAMBIAS ALGÚN ARCHIVO
  Abre sw.js y sube el número de la línea  const CACHE = 'bandas-en-casa-v5';
  (por ejemplo a v6). Así los móviles recogen la versión nueva.

TUS DATOS
  Se guardan solo en el navegador de cada dispositivo (el móvil y el ordenador
  tienen datos distintos). Usa Ajustes > Exportar para hacer copias e Importar
  para pasarlas de un dispositivo a otro (incluye rutinas, historial, carreras y tus fotos).
